## 1. High-Level Architecture & Root Layout

The repository is organized into decoupled microservices and platform layers:
- `backend/`: FastAPI Python 3.14 REST API engine with modular domain routers and concurrency protection.
- `frontend/`: React 19 + TypeScript + Vite Single-Page Application following Feature-Sliced domain modularity.
- `db/`: Canonical PostgreSQL 15 / Supabase schemas, GIN repertory indexes, and initial seeds.
- `infra/`: Docker Compose, Kong API Gateway declarative routes, and Nginx reverse-proxy configuration.
